Licences and shared work

Nyanime's private development does not change upstream licences. The complete release audit remains in progress. No approved proprietary application or application download is offered here.

AniYomi, Mihon and Tachiyomi

Nyanime derives from AniYomi and preserves work from Mihon, Tachiyomi and their contributors. Inherited code remains subject to its applicable Apache License 2.0 and original notices. Nyanime's changes do not claim ownership of those projects or marks. See the actual Apache License 2.0 and current project NOTICE.

A scoped proposal for original contributions

Lorenzo Garrone proposes proprietary protection only for original code/assets whose ownership can be established and whose release-specific scope is explicitly identified. That ownership schedule is incomplete. This does not relabel inherited code or revoke earlier grants. The full proposal and terms summary remain review drafts.

Native player and media libraries

A replacement mpv/FFmpeg/FFmpegKit set is being prepared with optional GPL components disabled. Those libraries retain their applicable LGPL obligations. The previous default player binaries are not made proprietary-compatible by this proposal. New native source packages exist locally; integration, exact-release verification and a working replacement/recomposition procedure are still being completed.

The relevant release must provide actual corresponding sources, changes, notices, build instructions and required application/object and installation materials. An upstream repository link does not replace that delivery. See FFmpeg's guidance and mpv's licence details.

Image decoding and other components

The image-decoder wrapper is MPL 2.0 and its native chain contains statically linked LGPL libraries. Covered source/modification rights and a usable recomposition route must be satisfied for the complete chain; that work is not yet finished.

Anime4K shaders use MIT; TDLib uses the Boost Software License. Archive, database, cryptography, downloader, UI, model, font and other asset licences must be checked against actual delivered versions, including native libraries behind wrappers. This page is not a complete release inventory.

Rights a proposed EULA must preserve

Open-source licences govern their components. The proposed Nyanime terms preserve LGPL modification, library replacement, relinking/recomposition and reverse engineering to debug library modifications, and MPL covered-source rights. Required materials must actually be supplied; contractual wording cannot replace them. Earlier open-source grants remain valid for their covered versions/material.

Release materials

Native component sources, notices and rebuild guides are available with exact archive hashes. These materials cover the development candidate’s selected native libraries. There is no application installer offered here, and Java/DEX delivery, application recomposition and runtime validation remain in progress. The final release must identify its exact shipped components and provide all materials required by their licences.

Portable sources and content

Independent .nyasource modules have their own licences and notices. Their signatures establish signing-key identity and integrity, not content ownership. Personal modules are outside the planned public distribution. The planned base app has no preinstalled sources, addons or developer-managed catalogue.
